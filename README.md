# 🍕 Pizza Sales Dashboard — Product Performance Analysis

## 📊 Project Overview

This project analyzes **10,000+ pizza sales records** to uncover key insights into product performance.
The goal is to identify **top-performing** and **slow-moving** pizzas, optimize inventory, and boost overall sales.

## 🧠 Objectives

* Analyze pizza sales data using **SQL**
* Identify best-selling and least popular pizzas
* Visualize performance trends using **Excel dashboards**
* Help management make data-driven inventory decisions

## 🛠 Tools & Technologies

* **SQL** – Data extraction and analysis
* **Microsoft Excel** – Data cleaning, pivot tables, and dashboard creation

## ⚙️ Key Insights

* Top 5 pizzas generated over **45% of total sales**
* Identified slow-moving pizzas to help reduce waste
* Sales peak observed during **weekends and evening hours**
